# Code of conduct

This project has no forum, no chat server, and no mailing list. The only place people
interact is the issue tracker.

## Expected there

- Argue about the code, the measurements, and the constraints. Bring numbers; that is
  what makes a disagreement resolvable.
- Say why you think a decision is wrong. That is useful, even when it changes nothing.
- Accept that a single maintainer may close a thread he does not want to spend a week
  on. That is capacity, not censorship.

## Not expected

- Personal attacks, or dismissing a report because of who filed it.
- Demands for a timeline, a fix, or a feature. There is no obligation to deliver any.
- Issue text with no board name, no log, and no reproduction. It gets closed as
  unactionable, which is not a judgement about you.

## Enforcement

An issue that breaks the above gets closed or locked. Repeated behaviour gets the
account blocked from the repository. There is no warning committee and no appeal
process.

Private reports go through the channel described in `SECURITY.md`.
